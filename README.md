# Angeline Suzanna-portfolio

## Project Overview
This is my personal portfolio website, created for the HCI Lab assignment. It introduces me, shows my technical skills and projects, and provides links to my contact information. The website is built using HTML and CSS.

- **Live Website:** https://a-suzanna.github.io/portfolio/
- **Canva Design:** https://canva.link/0da75433qw41k2m
- **GitHub Repository:** https://github.com/A-Suzanna/portfolio

## Purpose
The purpose of this website is to present my background, skills, and projects in one place. It also gives me a chance to apply what I've learned about HTML, CSS, and responsive web design.

## Target Audience
This portfolio is mainly for potential employers, recruiters, and anyone interested in my skills and projects.

## Technologies Used
- **HTML5:** Used to structure the website and its content.
- **CSS3:** Used to style the website and make the layout responsive.

## Website Sections
The website includes sections about me, my projects, my technical skills, and my contact information. It is designed to present the information in a clear and organized way.

## Responsive Design
The website is designed to work on desktop, tablet, and mobile screens using CSS and responsive layouts.

## How to Run the Website Locally
1. Clone the repository:

   `git clone https://github.com/A-Suzanna/portfolio.git`

2. Open the downloaded project folder.
3. Open `index.html` in your browser to view the website.
